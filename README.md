# UseTrace Studio — Документація кваліфікаційного проєкту

Головний навігаційний дашборд технічної документації та статус-трекер розробки кваліфікаційної роботи студента групи 441 кафедри ПЗКС Сусли Владислава Валерійовича.

---

## 📌 Паспорт проєкту

- **Тема:** «Розробка веб-системи наскрізного моделювання вимог до програмного забезпечення з реактивною двосторонньою генерацією UML-діаграм, верифікаційного беклогу та автоматизованою оцінкою трудовитрат»
- **Робоча назва:** UseTrace Studio (Enterprise Requirements Lifecycle, Visual Modeling & WBS Engine)
- **Спеціальність:** F2 / 121 «Інженерія програмного забезпечення»
- **Науковий керівник:** Комісарчук Володимир Васильович
- **Методологія:** Docs-as-Code
