# UseTrace Studio — Документація кваліфікаційного проєкту

Головний навігаційний дашборд технічної документації та статус-трекер розробки кваліфікаційної роботи студента групи 441 кафедри ПЗКС Сусли Владислава Валерійовича.

## 📌 Паспорт проєкту

- **Тема:** «Розробка веб-системи наскрізного моделювання вимог до програмного забезпечення з реактивною двосторонньою генерацією UML-діаграм, верифікаційного беклогу та автоматизованою оцінкою трудовитрат»
- **Робоча назва:** UseTrace Studio (Enterprise Requirements Lifecycle, Visual Modeling & WBS Engine)
- **Спеціальність:** F2 / 121 «Інженерія програмного забезпечення»
- **Науковий керівник:** Комісарчук Володимир Васильович
- **Методологія:** Docs-as-Code

## 📊 Матриця нефункціональних вимог (NFRs Matrix)

| ID | Ціль приймання |
| --- | --- |
| [PERF-01](./srs.md#srs-nfr-perf-01) | p95 TTFB < 150 мс при 500 RPS за профілем SRS. |
| [PERF-02](./srs.md#srs-nfr-perf-02) | p95 повного впорядкування < 50 мс для 10000 вузлів і 30000 ребер у RAM. |
| [SEC-01](./srs.md#srs-nfr-sec-01) | Валідний OIDC access token RS256 і права на конкретний проєкт. |
| [SEC-02](./srs.md#srs-nfr-sec-02) | 100 REST-запитів на IP за рухоме вікно 60 секунд; перевищення — HTTP 429. |
| [COMP-01](./srs.md#srs-nfr-comp-01) | Лише дозволені поля аудиту; персональні дані й секрети не записуються. |
| [REL-01](./srs.md#srs-nfr-rel-01) | Доступність ≥ 99,9% за 30 діб спостереження стенда. |

Це вимоги до перевірки; результати фактичних запусків зберігаються окремо.
